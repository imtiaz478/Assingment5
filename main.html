Question-1: What are the different ways to select an element in the DOM?

getElementById() , getElementsByClassName() , querySelector()

Question-2: What is the difference between innerHTML, innerText, and textContent ?

innerHTML : Returns or sets the HTML markup inside an element.
innerText : Returns or sets the visible text of an element
textContent : Returns or sets all the text inside an element

Question-3: What is event delegation in the DOM?

Event Delegation is a powerful technique in the DOM where instead of adding event listeners to multiple child elements, you add one single event listener to their parent element and handle events for all children through it.

Question-4: What is event bubbling in the DOM?

Event Bubbling is a concept in the DOM event flow where an event starts from the innermost (child) element that triggered it and then bubbles up to its parent, grandparent, and so on all the way up to the html element.
